# Sysmon Setup

1. Download Sysmon only from Microsoft's official Sysinternals source.
2. Select a documented configuration appropriate for the lab.
3. Install Sysmon with the selected configuration and verify the Sysmon service is running.
4. Confirm events appear in `Microsoft-Windows-Sysmon/Operational` in Event Viewer.
5. Record Sysmon version, configuration source/version, and sample event IDs.

Do not claim telemetry is collected until the events are verified in the Windows guest.
