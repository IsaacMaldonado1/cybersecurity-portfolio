# Controlled Attack Simulations

Document safe, repeatable simulations used to generate telemetry for detection validation. Each scenario should include:

- Objective and lab scope
- Preconditions and safety constraints
- Exact steps and expected telemetry
- Detection result and evidence
- Cleanup / reset procedure
- MITRE ATT&CK technique mapping, where applicable

Run scenarios only against the lab systems you control. Begin with benign actions and avoid destructive tests.
